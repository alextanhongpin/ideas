# Building

The wrong question to ask. usually the better question is what problem does it solve?

Without understanding the problem, it is hard to come up with a solution.

For example, I want AI to proof read my content. How can I build an AI agent for it.

That is the product goal.

We also want to look at the tech goal, which is understanding the success of the model.

This comes with a lot of work, such as understanding the hyperparameters bounds (which model, temperature) as well as model specific parameter like prompt. We also need to track the result, such as users evaluation vs llm evaluation.
